# Vietnamese Fake News Detection: A Comparative Study of Machine Learning Approaches

A research project comparing machine learning approaches for Vietnamese fake news detection, evaluating four models across three paradigms: **traditional ML** (Logistic Regression, SVM), **deep learning** (BiLSTM), and **transformer-based** (PhoBERT). The project ships a reproducible end-to-end pipeline (preprocessing → features → training → evaluation → statistical analysis → explainability → knowledge distillation) plus a **Streamlit demo** that runs the trained models on user-pasted Vietnamese news.

## Key Results

| Rank | Model               | Type           | Accuracy   | F1 (macro) | AUC    |
| ---: | ------------------- | -------------- | ---------- | ---------- | ------ |
|    1 | **PhoBERT**         | Transformer    | **90.07%** | **0.8988** | 0.9495 |
|    2 | SVM (LinearSVC)     | Traditional ML | 84.34%     | 0.8410     | 0.9190 |
|    3 | Logistic Regression | Traditional ML | 83.48%     | 0.8329     | 0.9188 |
|    4 | BiLSTM              | Deep Learning  | 82.52%     | 0.8232     | 0.9048 |

PhoBERT outperforms all baselines on the test set (verified via **McNemar's test, p < 0.001** with Holm–Bonferroni correction). Knowledge Distillation ships a Student BiLSTM (~100× smaller) that retains most of PhoBERT's F1 — see the [Distillation step](#step-7-knowledge-distillation-optional).

## Installation

> **Supported Python versions: 3.10, 3.11, or 3.12.**
> Python 3.13+ is **not yet supported** because `fasttext-wheel 0.9.2` does not compile against its bundled C++ headers on newer Python versions. See [`pyproject.toml`](pyproject.toml) for the canonical constraint.

```bash
cd FakeNewsDetector

# 1. Create a virtual env with a supported Python
python3.11 -m venv .venv
source .venv/bin/activate

# 2. Install the project + all pinned deps
pip install -e .

# 3. (Optional) Install the Streamlit demo deps
pip install -e ".[demo]"

# 4. (Optional, Linux only) Py_VnCoreNLP requires Java
export JAVA_HOME=/usr/lib/jvm/java-25-openjdk   # adjust to your Java path
```

**Pinned tools** (see `pyproject.toml`): `numpy ≈ 2.4.1`, `pandas ≈ 3.0.0`, `scikit-learn ≈ 1.8.0`, `scipy ≈ 1.17.0`, `torch ≈ 2.10.0`, `transformers ≈ 4.57.6`, `sentencepiece ≈ 0.2.1`, `py_vncorenlp ≈ 0.1.4`, `underthesea ≈ 9.1.4`, `fasttext-wheel ≈ 0.9.2`, `matplotlib ≈ 3.10.8`, `seaborn ≈ 0.13.2`, `streamlit ≥1.39,<2`, `shap ≥0.45`, `captum ≥0.7`.

> **Automatic downloads on first run**
>
> - The **VnCoreNLP jar** (~140 MB) is downloaded by `py_vncorenlp` into `.vncorenlp/` on first segmentation call.
> - **PhoBERT** (`vinai/phobert-base`) is downloaded from the HuggingFace Hub on first fine-tuning run and cached under `data/features/phobert_tokenizer_cache/`.
>
> Both are excluded from the submission archive — the pipeline reproduces them deterministically.

## Optional: Vietnamese FastText embeddings (BiLSTM only)

`FastText` is **only** used by **BiLSTM**, to bootstrap its word-embedding matrix from Vietnamese `cc.vi.300.bin`. Everything else (LR / SVM / PhoBERT) works out-of-the-box without it. If the file is missing, `train_bilstm.py` will now **warn and continue with random embeddings** rather than crash (see commit history — was crashing previously). So you can skip this step entirely if you just want PhoBERT or the baselines to train.

### File facts

- **Filename**: `cc.vi.300.bin` (binary `.bin`, **not** `.vec`)
- **Size**: ≈ **4.2 GB**
- **Source page**: <https://fasttext.cc/docs/en/crawl-vectors.html>
- **Default location** (after install): `data/fasttext/cc.vi.300.bin`
  — already excluded by `.gitignore`, so each user downloads their own copy.

### Option A — Direct download (canonical FastText site)

```bash
mkdir -p data/fasttext
cd data/fasttext

# Option A1: wget (Linux)
wget -c https://dl.fbaipublicfiles.com/fasttext/vectors-crawl/cc.vi.300.bin.gz \
     -O cc.vi.300.bin.gz

# Option A2: curl (macOS / any Unix)
curl -L --fail -o cc.vi.300.bin.gz \
     https://dl.fbaipublicfiles.com/fasttext/vectors-crawl/cc.vi.300.bin.gz

# Decompress (~800 MB → 4.2 GB). Do NOT remove the .gz until you've verified the hash.
gunzip cc.vi.300.bin.gz

# Sanity check
ls -lh cc.vi.300.bin                     # ~4.2G
file cc.vi.300.bin                       # should report "data"
```

### Option B — Hugging Face mirror (often faster from Asia / when fbaipublicfiles is slow)

A community mirror is published on the Hugging Face Hub under
[`facebook/fasttext-vi-vectors`](https://huggingface.co/facebook/fasttext-vi-vectors) (or any
mirror of your choice — search "cc.vi.300.bin" on the Hub).

```bash
# B1: huggingface-cli (recommended — comes with `pip install -e .` already)
pip install -U "huggingface_hub>=0.20"
huggingface-cli download \
    facebook/fasttext-vi-vectors \
    cc.vi.300.bin \
    --local-dir data/fasttext \
    --include "cc.vi.300.bin"

# B2: from Python (no CLI needed)
python - <<'PY'
from huggingface_hub import hf_hub_download
import os
os.makedirs("data/fasttext", exist_ok=True)
p = hf_hub_download(
    repo_id="facebook/fasttext-vi-vectors",
    filename="cc.vi.300.bin",
    local_dir="data/fasttext",
)
print("Downloaded to:", p)
PY
```

> If the Hub path above ever goes stale, just `huggingface-cli download <any-mirror> cc.vi.300.bin --local-dir data/fasttext` — every public mirror produces a bit-identical `.bin`.

### Verify the download

```bash
cd data/fasttext
ls -lh cc.vi.300.bin        # ~4.2G
md5sum  cc.vi.300.bin       # (optional; FastText does not publish a single canonical MD5 for cc.vi.300.bin)
```

A working file:

- has size ≈ **4.2 GB**,
- is reported as `data` by `file(1)`,
- and `head -c 4 cc.vi.300.bin | xxd` should show `…` followed by ASCII header line for `cc.vi.300`.

### Sanity-check BiLSTM can read it

```bash
source .venv/bin/activate
python -c "
import fasttext, os
p = 'data/fasttext/cc.vi.300.bin'
print('exists?', os.path.exists(p), 'size:', os.path.getsize(p))
m = fasttext.load_model(p)
print('vec dim:', m.get_dimension(), 'sample:', m.get_word_vector('việt_nam')[:3])
"
```

### Re-train BiLSTM with pretrained embeddings

Once `cc.vi.300.bin` is in place, `cfg.BILSTM.fasttext_path` already points at it, so just re-launch:

```bash
# remove the previous BiLSTM artefacts to force a fresh run with pretrained init
rm -rf experiments/bilstm
fakenews train bilstm
```

The training log will say `Loading FastText embeddings from ...` and F1 should improve over the random-init baseline. If you ever want to _disable_ pretrained init, set in `config.py`:

```python
@dataclass
class BiLSTMConfig:
    fasttext_path: str = ""    # empty string → skip pretrained init
```

### Step-by-step (what each command does, what it reads, what it produces)

#### Step 0 — Activate the environment

```bash
cd FakeNewsDetector
source .venv/bin/activate          # Linux / macOS
# .venv\Scripts\activate            # Windows
pip install -e .                   # if not done yet
```

#### Step 1 — Word Segmentation

```bash
fakenews preprocess
# or, equivalently:
python -m src.preprocessing.word_segmentation
```

- **Reads**: `data/raw/raw.csv` (15,789 rows × columns `id, text, date, label`).
- **What happens**: First, the text cleaner (`TextPreprocessor`) normalizes whitespace, lowercases, strips URLs, deduplicates. Then, every document is tokenised into Vietnamese compounds using **`py_vncorenlp`** with the RDRSegmenter annotator (falls back to `underthesea.word_tokenize` if Java/VnCoreNLP is unavailable). E.g. "Hà Nội là thủ đô" → "Hà*Nội là thủ*đô".
- **Writes**: `data/processed/segmented.csv` with word-segmented `text` (≈ 13,958 rows after cleaning — see Dataset).
- **Wall-clock**: 5–15 min on CPU depending on Java availability. Re-runnable: if `segmented.csv` exists, skip and go to Step 2.

#### Step 2 — Train / Val / Test Split

```bash
fakenews split
# or:
python -m src.preprocessing.split_data
```

- **Reads**: `data/processed/segmented.csv`.
- **What happens**: `train_test_split` × 2 — first 70 % train + 30 % {val, test}, then 50/50 of the remainder for val/test. Both splits are stratified on `label`. `verify_no_leakage()` checks for **text-level and ID-level overlap** and fails loudly if found.
- **Writes**:
  - `data/splits/train.csv` — 9,770 rows
  - `data/splits/val.csv` — 2,094 rows
  - `data/splits/test.csv` — 2,094 rows
- **Tip**: set `cfg.DATA.train_ratio / val_ratio / test_ratio` or `cfg.RANDOM_STATE` in `config.py` if you want a different split.

#### Step 3 — Feature Extraction

```bash
fakenews features
# or:
python -m src.features.extract_all_features
```

This step extracts **three parallel feature pipelines**:

| Pipeline                     | Trainable module                                      | Output file(s)                                                              | Notes                                                                                                                                                                                                                                                                     |
| ---------------------------- | ----------------------------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **TF-IDF**                   | `TfidfFeatureExtractor`                               | `data/features/tfidf/tfidf_vectorizer.pkl`, `tfidf_features.pkl`            | `max_features=40 000`, `ngram_range=(1,2)`, `min_df=5`, `max_df=0.95`, `sublinear_tf=True`                                                                                                                                                                                |
| **Word embeddings (BiLSTM)** | `EmbeddingFeatureExtractor`                           | `data/features/embedding/embedding_extractor.pkl`, `embedding_features.pkl` | `max_seq_len=128`, `min_freq=2`, optional **FastText `cc.vi.300.bin`** init for the embedding matrix (see [Optional: Vietnamese FastText embeddings](#optional-vietnamese-fasttext-embeddings-bilstm-only); missing file is non-fatal — BiLSTM falls back to random init) |
| **PhoBERT**                  | `AutoTokenizer.from_pretrained("vinai/phobert-base")` | `data/features/phobert/phobert_features.pkl`, `phobert_tokenizer_cache/`    | `max_seq_len=256`, returns `input_ids` + `attention_mask` per document                                                                                                                                                                                                    |

- **Wall-clock**: ~30 s for TF-IDF, a few minutes for word embeddings, **5–10 min on GPU** (or ~30 min on CPU) for PhoBERT tokenisation. If only TF-IDF / BiLSTM are trained, you can skip PhoBERT feature extraction.

#### Step 4 — Train the 4 Models

You can train them all or pick the ones you need. Models are saved under `experiments/<dir>/` with the **same folder name** for every command so downstream scripts can rely on `MODEL_DIR_MAP`.

```bash
fakenews train all             # or: fakenews train lr svm bilstm phobert

# per-model:
fakenews train lr              # Logistic Regression (GridSearchCV, 5-fold)
fakenews train svm             # LinearSVC + calibration (GridSearchCV, 5-fold)
fakenews train bilstm          # BiLSTM (AdamW + cosine schedule, early stopping)
fakenews train phobert         # PhoBERT (layer-wise LR decay + linear warmup)
```

- **Reads**: feature `.pkl` files from Step 3.
- **What happens (per model)**:
  - **Logistic Regression** — TF-IDF features → `LogisticRegression(max_iter=3000, class_weight='balanced', solver in {liblinear, saga})` tuned via `GridSearchCV` over `{C: 0.5, 1, 5, 10, 20, 50}`. Saves `lr_model.pkl`.
  - **SVM** — Same TF-IDF features → LinearSVC (calibrated for `predict_proba`) tuned over `{C: 0.1, 0.5, 1, 2, 5, 10}`. Saves `svm_model.pkl`.
  - **BiLSTM** — Random-init or FastText-init embeddings → 1-layer BiLSTM, hidden 128, dropout 0.3, AdamW + cosine LR. Early stopping on val F1 (`patience=5`). Saves `bilstm_model.pt` (incl. `training_history` + best state). _To enable pretrained Vietnamese embeddings, see [Optional: Vietnamese FastText embeddings](#optional-vietnamese-fasttext-embeddings-bilstm-only) — `cc.vi.300.bin` is downloaded by the user, not the project._
  - **PhoBERT** — `vinai/phobert-base` fine-tuned with **layer-wise LR decay (0.95)**, AdamW, linear warmup (10 %), batch 16 × grad accum 4 (=64 effective), up to 8 epochs, `patience=2`. Saves `phobert_model.pt`.
- **Writes** (each model):
  - `experiments/<dir>/<model>_model.{pkl,pt}` — the trained model.
  - `experiments/<dir>/predictions.pkl` — `{y_true, y_pred, y_prob}` on the test set.
  - `experiments/<dir>/metrics.json` — full metric dict (accuracy, f1_macro, per-class, confusion matrix, …).
  - `experiments/<dir>/experiment_log.json` — appended by `ExperimentTracker` (git commit, config hash, run timestamp).
- **Wall-clock**:
  - LR / SVM: seconds.
  - BiLSTM (CPU): 10–30 min for 20 epochs.
  - PhoBERT (single GPU): 30–90 min for 8 epochs.

#### Step 5 — Evaluation (Comparison, Figures, Tables)

```bash
fakenews evaluate
# or:  python -m src.evaluation.evaluate_all
```

- **Reads**: `experiments/**/predictions.pkl` + `metrics.json` + the training history baked into the `.pt` checkpoints.
- **What happens**:
  - Loads all metrics via `load_all_metrics()` → builds comparison / per-class DataFrames.
  - Re-runs predictions on the test set for any model whose `predictions.pkl` is missing.
  - Plots **4 figures** + **2 LaTeX tables** + **2 CSVs** + a `evaluation_summary.json`.
- **Writes**:
  - `results/figures/model_comparison.png` — grouped bar chart of accuracy / precision / recall / F1.
  - `results/figures/confusion_matrices.png` — 2×2 grid of conf-matrices with accuracy annotations.
  - `results/figures/roc_curves.png` — ROC curves for all 4 models + random baseline.
  - `results/figures/training_history.png` — train/val loss + val F1 vs epoch for BiLSTM & PhoBERT.
  - `results/tables/model_comparison.{csv,tex}` — overall comparison.
  - `results/tables/per_class_metrics.csv` — per-class precision/recall/F1.
  - `results/tables/evaluation_summary.json` — best model, improvement over baseline, full results.

### Optional analysis steps

#### Step 6 — Calibration Analysis

```bash
fakenews calibration            # → src.evaluation.calibration_analysis
fakenews recalibrate            # → src.evaluation.post_hoc_calibration
```

- **Calibration** computes **ECE, MCE, Brier** and renders a 4-panel reliability diagram.
- **Post-hoc recalibration** sweeps **Platt scaling, Temperature scaling, and Isotonic regression** and writes the best calibrator per model.
- **Writes**: `results/figures/reliability_*.png`, `paper/tables/table_post_hoc.tex`, recalibrated checkpoints under `experiments/<dir>/`.

#### Step 7 — Explainability (Token-Level Attribution)

```bash
# default 20 examples
fakenews explain

# customise
fakenews explain --n-examples 30 --output-dir results/attributions \
                 --figures-dir paper/figures --tables-dir paper/tables
```

- Picks examples by _difficulty bucket_ (hard / borderline / easy) using the per-id confidence table.
- Runs **per-model, per-example token attribution**:
  - LR / SVM → `KernelSHAP` over TF-IDF.
  - BiLSTM → `Integrated Gradients` + simple gradients over the embedding layer.
  - PhoBERT → `SHAP`, `Integrated Gradients`, `Attention Rollout`.
- Aggregates with:
  - Method-agreement heatmap (`fig_method_agreement.png`).
  - Cross-model top-K Jaccard agreement (`fig_cross_model_agreement.png`).
  - Faithfulness table (`table_attribution_faithfulness.tex`) — probability drop after masking the top-5 tokens.
- **Writes**: per-example `.pkl` attributions under `results/attributions/<id>.pkl`, aggregate figures under `paper/figures/`, table under `paper/tables/`.

#### Step 8 — Knowledge Distillation (optional)

```bash
# default: train student + render trade-off figure
fakenews distill

# train only / eval only / everything
fakenews distill --mode train
fakenews distill --mode eval

# knobs
fakenews distill --alpha 0.7 --temperature 4.0 --epochs 30 --patience 5 \
                 --teacher-model bert --n-runs 30
```

- Trains a **Student BiLSTM** (smaller hidden dim / fewer layers) under a **KL + CE** loss against the PhoBERT (or BiLSTM) teacher logits.
- Measures **F1 vs #params vs size (MB) vs latency (ms)** for teacher(s) + student.
- **Writes**:
  - `experiments/student_bilstm/{student_bilstm_model.pt, metrics.json, …}`.
  - `paper/tables/table_distillation.tex` — comparison table.
  - `paper/figures/fig_distillation_tradeoff.{png,pdf}` — F1-vs-size scatter.
- Typical outcome (verified): **~100× compression** of PhoBERT at the cost of ~3 F1 points, with significantly faster inference.

#### Step 9 — Hard-Cases Deep-Dive (optional)

```bash
fakenews hard-cases
# or with custom paths:
fakenews hard-cases --per-id-confidence results/tables/per_id_confidence.csv \
                    --test-csv data/splits/test.csv \
                    --attributions-dir results/attributions \
                    --figures-dir paper/figures --tables-dir paper/tables
```

- Selects samples wrong by **all 4 models** and overlays their per-token attributions.
- **Writes**: a distribution figure (failure rate by length / class) and an annotated LaTeX table under `paper/tables/`.

### What the demo shows

- **Prediction card** — REAL/FAKE with confidence, plus a probability bar for P(Real) / P(Fake).

## Dataset

- **Raw**: 15,789 Vietnamese news articles.
- **Schema**: `id, text, date, label` (`label ∈ {0=Real, 1=Fake}`).
- **After cleaning**: 13,958 articles.
- **After segmentation**: same row count, segments like `Hà_Nội`, `thủ_đô` (joined by underscores for TF-IDF).
- **After split**: 9,770 / 2,094 / 2,094 (train/val/test).
- **Class balance** (cleaned): Real (55.6 %) / Fake (44.4 %).
- **Preprocessing**: `py_vncorenlp` RDRSegmenter (with `underthesea` fallback), URL removal, whitespace normalisation, drop rows with `< cfg.DATA.min_word_count` (default 10).
- **Stratified split** at every stage; **text + ID leakage checked** after split.
- **Data-leak warning** (read this): URLs and `@mention` markers are **highly correlated with the Fake label** in this corpus. URL stripping mitigates but does not eliminate the signal — see `RESEARCH_ARCHITECT_REPORT.md` for the full audit.

## Statistical Validation & Analysis

Implemented in `src/analysis/` and `src/evaluation/`:

- **McNemar's test** (pairwise) with **Holm-Bonferroni** correction for multiple comparisons (`statistical_tests.py:mcnemar_test`, `holm_bonferroni_correction`).
- **Bootstrap 95 % CI** for accuracy & F1 (`bootstrap_confidence_interval`, default `n=10 000`).
- **Cohen's d** effect size for PhoBERT vs each baseline.
- **Calibration**: ECE, MCE, Brier + reliability diagrams (`calibration_analysis.py`).
- **Post-hoc calibration**: Platt / Temperature / Isotonic sweep with reliability comparison (`post_hoc_calibration.py`).
- **5-fold cross-validation × 3 seeds** for the two traditional ML models (`cross_validation.py`).
- **Ablation study** (LR-only): TF-IDF vocab size, n-gram range, segmentation, regularisation C, sublinear TF (`ablation_study.py`).
- **Hard-cases & error analysis**: per-id confidence, common failure patterns by length/class, samples wrong by all 4 models (`error_analysis.py`, `hard_cases.py`).
- **Token-level attribution** (SHAP / IG / attention rollout) for **all 4 models**, with cross-model top-K agreement and faithfulness table.

## Configuration (`config.py`)

Everything tunable lives in **`config.py`** as dataclasses (`Paths`, `DataConfig`, `TFIDFConfig`, `LRConfig`, `SVMConfig`, `BiLSTMConfig`, `PhoBERTConfig`, `AnalysisConfig`) bound to a single `cfg` singleton. Import it as:

```python
from config import cfg
print(cfg.PHOBERT.learning_rate)
print(cfg.DATA.train_ratio)
```

Notable knobs:

- `cfg.RANDOM_STATE = 42` — master seed (used in `set_reproducibility_seeds`).
- `cfg.TFIDF.max_features = 40 000`, `cfg.TFIDF.ngram_range = (1, 2)`.
- `cfg.LR.param_grid` — GridSearchCV space.
- `cfg.SVM.use_linear = True` — uses `LinearSVC` + calibrated CV.
- `cfg.BILSTM.fasttext_path` — set to `data/fasttext/cc.vi.300.bin` to bootstrap BiLSTM embeddings. The file is downloaded by the user from <https://fasttext.cc/docs/en/crawl-vectors.html> — see the [Optional: Vietnamese FastText embeddings](#optional-vietnamese-fasttext-embeddings-bilstm-only) section for copy-pasteable `wget`, `curl`, and `huggingface-cli` commands. Leave it as-is to keep the default location.
- `cfg.PHOBERT.layer_lr_decay = 0.95`, `cfg.PHOBERT.gradient_accumulation_steps = 4`.
- `cfg.ANALYSIS.bootstrap_iterations = 10 000`, `significance_level = 0.05`.
